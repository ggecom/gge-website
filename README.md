# نشر موقع GGE على GitHub Pages

هذه ملفات موقع ثابت بلا اشتراك أو أدوات بناء أو خدمات خارجية لازمة للتشغيل. لا تنشر ملف ZIP نفسه: فك الضغط وارفع محتويات هذا المجلد إلى جذر مستودع `ggecom/gge-website`.

## من شاشة index.html الفارغة حاليًا

1. افتح `index.html` من الحزمة وانسخ محتواه كاملًا إلى محرر GitHub، ثم اختر Commit changes.
2. من صفحة المستودع اختر Add file → Upload files، وارفع `style.css` و`app.js` ومجلدي `assets` و`documents` والملف `.nojekyll`. ارفع المجلدات بمحتوياتها وحافظ على أسمائها. لا تضعها داخل مجلد إضافي باسم gge-website.
3. Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save. إذا كان اسم الفرع مختلفًا فاختر الفرع الذي رفعت إليه الملفات.
4. بعد نجاح النشر راجع https://ggecom.github.io/gge-website/ واختبر اللغة وتحميل PDF والاتصال.

الاستضافة مجانية عبر GitHub Pages للمستودعات العامة وفق خطة GitHub وشروطها. لا توجد استمارة إرسال أو قاعدة بيانات؛ روابط التواصل تفتح تطبيق الهاتف أو البريد.

## النطاق والبريد — اقرأ قبل الربط

- النطاق المستهدف بطلب المستخدم: `gge.com.sa`.
- الملفات الأصلية تذكر `www.gge-saudi.com` للموقع، وتذكر `sales@gge.com.sa` و`info@gge.com.sa` للبريد. اختلاف النطاقين محفوظ في هذه الملاحظة؛ لم نعتمد gge-saudi.com كنطاق مستهدف.
- لم يُضف ملف CNAME عمدًا: شغّل الموقع أولًا على عنوان GitHub Pages. لم تُجرَ أي تغييرات DNS.
- عند ربط النطاق لاحقًا، تحقق من ملكيته في GitHub أولًا ثم استخدم Settings → Pages → Custom domain واكتب `gge.com.sa`. راجع تعليمات GitHub الرسمية الحالية لتحديد سجلات الويب الصحيحة وتفعيل HTTPS.
- احتفظ بنسخة من منطقة DNS قبل أي تعديل. سجلات Microsoft 365، خصوصًا MX وTXT الخاصة بـSPF والتحقق وDKIM وDMARC وautodiscover وأي SRV للبريد، يجب أن تبقى كما هي. لا تغيّر خوادم الأسماء NS ولا تستبدل منطقة DNS كاملة. قد توجد سجلات ويب متعارضة يجب مراجعتها وحدها.
- لا تربط النطاق قبل تجهيز الاستضافة والتحقق من الملكية. لا تنشر بريدًا أو هاتفًا جديدًا بناءً على تخمين.

التعليمات الرسمية: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site و https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site

## المحتوى والمصادر

الصور والشعار مستخرجة من ملفات المؤسسة المرفقة، والمستندات الأصلية متاحة في documents. الصور التوضيحية للخدمات مأخوذة من ملفات التعريف ولا تُعرض كصور لمشاريع بعينها. البيانات المنشورة: الهاتف +966 57 372 2361، الخبر، سجل تجاري 2051229974، رقم موحد 7017013256، رقم ضريبي 310554599700003.

نطاق دعم النفط والغاز صياغة خدمية بناءً على طلب المستخدم وخدمات المؤسسة، وليس ادعاء اعتماد من جهة نفطية.

ملف الكبائن يتضمن مواصفات كهربائية مثل 110V؛ لذلك لم تُنقل تفاصيلها إلى نص الصفحة كتصميم نهائي معتمد للموقع. راجع المواصفات وتوافقها مع متطلبات المشروع عند التسعير.

لتعديل النصوص: المحتوى العام في index.html، والخدمات في app.js. يوجد النص العربي والإنجليزي لكل عنصر. لا يحتاج الموقع إلى تثبيت أي حزم.
